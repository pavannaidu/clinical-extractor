# Demo Paths

This folder contains guided, customer-facing walkthroughs that reuse the existing runnable code in `src/`.

## Available Demo Paths

- [interactive-comparison.md](interactive-comparison.md)
  Compare FMAPI and custom endpoints in the app.
- [custom-model-structured-output.md](custom-model-structured-output.md)
  Show MedGemma + XGrammar serving with caller-supplied schema.
- [batch-inference-at-scale.md](batch-inference-at-scale.md)
  Show how structured extraction scales across note volumes.

## How to Use This Folder

1. Pick a workload pack under `../workloads`.
2. Pick a demo path here.
3. Run the commands or app walkthrough using the schema and sample text from that workload pack.
