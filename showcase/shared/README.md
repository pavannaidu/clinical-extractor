# Shared Showcase Assets

This folder holds reusable presentation assets that support multiple workload packs and demo paths.

## Contents

- `system-prompts/clinical-extraction.txt`
  Baseline extraction prompt for schema-driven clinical workflows.
- `references/app-preset-mapping.md`
  How current app presets map to the showcase workload taxonomy.
- `references/models-catalog.md`
  Notes on how `src/app/models.json` is used in the app comparison story.

## Source of Truth

The runnable source of truth remains in `src/`. These shared files exist to make the showcase easier to navigate and reuse in demos.
