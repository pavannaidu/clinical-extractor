# Workload Packs

Each workload pack is designed to be presentation-ready and execution-ready.

## Included Workloads

- `ehr-clinical-notes`
- `adverse-event-reporting`
- `clinical-trial-data-capture`
- `prior-authorization`
- `drug-interaction-screening`

## What Each Pack Contains

- `README.md`
- `sample-note.txt`
- `schema.json`
- `system-prompt.txt`
- `expected-fields.md`

## How to Use

1. Pick the workload closest to the customer conversation.
2. Use the sample note, schema, and prompt in the app or endpoint request.
3. Pair it with a demo path from `../demos`.
