Option 3 · Fine-tuned custom LLM

Fine-tune only after a held-out review isolates repeatable semantic errors.

The schema, source set, and reviewer rubric stay fixed while model behavior changes.

Gate 1

Measure the gap

Label recurring semantic errors on a reviewed baseline.

Gate 2

Adapt behavior

Train on adjudicated examples with LoRA, QLoRA, or full fine-tuning.

Gate 3

Track + govern

Use MLflow for experiments and Unity Catalog for the deployable model.

Gate 4

Re-score + serve

Compare the same holdout, then deploy with the vLLM serving and inference engine plus XGrammar.

Fine-tuning Improves the probability of choosing the right clinical value.
≠
XGrammar Ensures the generated value lands in valid JSON.
Decision: Ship only when critical-field precision/recall improves materially without unacceptable omissions, latency, or cost.
